# ACNH 3.0.3 | 21:9 Ultrawide Mod

Adds 21:9 ultrawide support to Animal Crossing: New Horizons, allowing the game world to render beyond its original 16:9 aspect ratio.

## Compatibility

- **Game version:** Tested only on ACNH 3.0.3
- **Emulator:** Tested on Eden
- **Aspect ratio:** 21:9 (3440×1440)
- **60 FPS:** Compatible with [ACNH 60 FPS + SpeedFix (3.0.X)](https://gamebanana.com/mods/722295)
- **Other versions, emulators, and mods:** Not tested

## Installation (Eden)

1. Download and extract the mod archive.
2. Open Eden and right-click **Animal Crossing: New Horizons**.
3. Select **Open Mod Data Location**.
4. Place the extracted mod folder inside this directory, keeping its original internal file structure.
5. Restart Eden.
6. Right-click the game, select **Configure Game → Add-Ons**, and ensure the ultrawide mod is enabled.
7. Configure the emulator for 21:9 output and launch the game.

## Known Issues

The following issues are present in the current release:

- **Loading screens:** Overlays only cover the original 16:9 area, leaving terrain and other assets visible along the sides during transitions.
- **Object culling:** Trees may briefly appear or disappear near the upper-left and upper-right corners of the screen.
- **UI positioning:** HUD and interface elements remain positioned within the original 16:9 boundaries rather than extending to the ultrawide edges.
- **Performance:** Some performance issues remain under investigation.

These issues are not yet fixed.

## Notes

- Only ACNH version 3.0.3 running on Eden has been tested.
- Compatibility with the linked 60 FPS patch has been confirmed. Other FPS patches and mods have not been tested.
- Back up your existing mod files before installing or replacing patches.
